# 📚 Employee Leave Management System

A web-based Employee Leave Management System developed using **Python, Flask, SQLite, HTML, CSS, and Bootstrap**. This application allows employees to apply for leave online while enabling administrators to manage leave requests efficiently.

---

## 🚀 Features

### 👨‍💼 Employee Module
- Employee Registration
- Secure Login
- Dashboard
- Apply for Leave
- View Leave History
- Update Profile
- Logout

### 👨‍💻 Admin Module
- Admin Login
- Dashboard
- View Employees
- Approve Leave Requests
- Reject Leave Requests
- Manage Leave Records

---

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5

- Bootstrap 5

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/karanamlikith58-coder/Employee-Leave-Management-System.git
```

Go to the project folder

```bash
cd Employee-Leave-Management-System
```

Install dependencies

```bash
pip install flask
```

Run the application

```bash
python app.py
```

Open in browser

```
http://127.0.0.1:5000
```
